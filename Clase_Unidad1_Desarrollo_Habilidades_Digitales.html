1.1 Introducción a las TIC

Las Tecnologías de la Información y Comunicación (TIC) son el conjunto de herramientas, equipos y sistemas que nos permiten crear, almacenar, procesar y compartir información de forma digital: desde una computadora y un teléfono inteligente, hasta el internet y las plataformas en la nube.

Analogía

Piensa en las TIC como el sistema nervioso de una ciudad moderna: así como las neuronas transportan señales entre el cerebro y el cuerpo para que reaccionemos a tiempo, las TIC transportan datos entre personas, empresas y gobiernos para que la información llegue a donde se necesita, en el momento en que se necesita.

La alfabetización digital es, entonces, la capacidad de "hablar ese idioma": saber usar el equipo, el software y la información disponible para resolver problemas cotidianos, académicos y profesionales.

"No necesitas ser programador para dominar las TIC. Necesitas entender qué herramienta usar, cuándo usarla y por qué." — Mixtle

1.2 Hardware y software del PC

Toda computadora combina dos tipos de componentes que dependen uno del otro para funcionar.

Hardware — el cuerpo

Son los componentes físicos y tangibles: se pueden tocar.

  • Procesador (CPU) — el "cerebro" que ejecuta instrucciones
  • Memoria RAM — la mesa de trabajo donde se procesa todo temporalmente
  • Disco duro / SSD — el almacén de archivos permanentes
  • Periféricos — teclado, mouse, monitor, impresora
Software — la mente

Son los programas e instrucciones: no se tocan, se ejecutan.

  • Sistema operativo — organiza y administra todo el equipo
  • Software de aplicación — Word, Excel, un navegador, un videojuego
  • Controladores (drivers) — traducen instrucciones para el hardware

Analogía: el hardware es como el cuerpo humano (huesos, músculos, órganos) y el software es como la mente (pensamientos, decisiones, instrucciones). Un cuerpo sin mente no actúa con propósito; una mente sin cuerpo no puede ejecutar nada en el mundo físico. Ambos son indispensables.

1.3 Sistemas operativos y su evolución

El sistema operativo (SO) es el software principal que administra los recursos del equipo (memoria, procesador, archivos, periféricos) y permite que los demás programas funcionen.

Analogía

Un sistema operativo funciona como el gerente de un edificio de oficinas: decide qué piso ocupa cada empresa (programa), reparte la electricidad y el agua (memoria y procesador) entre todos los inquilinos, y evita que dos empresas se peleen por el mismo espacio (conflictos de recursos).

  • Décadas de 1970-1980 · Interfaces de textoSistemas como MS-DOS y UNIX: el usuario escribía comandos de texto para dar instrucciones.
  • Década de 1990 · Interfaces gráficasWindows y macOS introducen ventanas, íconos y mouse: la computación se vuelve accesible para el público general.
  • Década de 2000 · Sistemas libres y establesDistribuciones de Linux ganan terreno en servidores y desarrollo por su estabilidad y código abierto.
  • 2007 en adelante · MovilidadiOS y Android llevan el sistema operativo al bolsillo, priorizando pantallas táctiles y aplicaciones.
  • Actualidad · Nube e integraciónLos sistemas operativos se conectan permanentemente a la nube, sincronizando archivos y aplicaciones entre dispositivos.

1.4 Herramientas de Office

La suite de Office es como una caja de herramientas: cada programa está diseñado para un trabajo específico, igual que un destornillador no sirve para martillar un clavo.

Herramienta¿Para qué sirve?Ejemplo de uso cotidiano
WordRedacción y formato de documentosUn reporte, una carta, una tesis
ExcelCálculo, organización de datos y fórmulasUn presupuesto, una lista de calificaciones
PowerPointPresentación visual de ideasUna exposición o pitch de proyecto
OutlookCorreo electrónico y agendaCoordinar una reunión de equipo
Regla práctica para elegir la herramienta correcta: ¿Necesito escribir? → Word  |  ¿Necesito calcular u organizar datos? → Excel  |  ¿Necesito mostrar ideas? → PowerPoint

1.5 Navegación y evaluación de información en la web

No toda la información que aparece en internet es confiable. Antes de usar una fuente para un trabajo académico o una decisión importante, conviene actuar como detective digital: revisar las pistas antes de creer al "testigo".

Lista de verificación del detective digital
  • AAutoría: ¿quién escribió el contenido? ¿tiene experiencia o credenciales sobre el tema?
  • FFecha: ¿la información está actualizada o es obsoleta?
  • OObjetividad: ¿el sitio intenta informar o vender/convencer de algo?
  • RRespaldo: ¿cita fuentes verificables, datos o referencias?
  • PPropósito: ¿el contenido responde exactamente a lo que necesito investigar?

Nota: dominios como .edu y .gob, así como los repositorios académicos, suelen ofrecer mayor confiabilidad que blogs personales o redes sociales sin autoría clara — aunque siempre conviene verificar.

Conclusión

La alfabetización digital no consiste en memorizar el nombre de cada componente o programa, sino en entender cómo se relacionan entre sí: el hardware ejecuta, el software instruye, el sistema operativo organiza, las herramientas de Office producen y la evaluación crítica de la información protege la calidad de todo lo que construimos con ellas. Dominar esta base te permitirá avanzar con confianza hacia los temas de seguridad, colaboración digital, creación de contenido y resolución de problemas técnicos que veremos en las siguientes unidades.
